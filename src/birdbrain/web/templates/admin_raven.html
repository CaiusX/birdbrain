Opening it in Raven

The zip holds a tab-delimited sound selection table and an audio/ folder of FLAC. Raven reads WAVE, AIFF, FLAC and MP3 — not the OGG Vorbis we store — so the clips are transcoded on the way out. FLAC is lossless and about a third the size of WAV; the as WAV link is there if a particular Raven build objects. The stored clips are Vorbis, so its artefacts are already in the audio: the transcode preserves them exactly rather than adding more.

The zip holds a tab-delimited sound selection table and an audio/ folder. In Raven Pro: File > Open Sound Files…, select everything in audio/ and open them as a single sequence, then File > Open Selection Table… and pick the .selections.txt.

Each row boxes the 3 second window BirdNET fired on, which is the last 3 seconds of each clip — the first 3 seconds is pre-roll context, kept deliberately so a call that starts early is not clipped. Frequency bounds are the species' typical band, the same one the review page draws.

The Label column is ours and is how a reviewed table comes back. Annotate it in Raven and keep the column.
